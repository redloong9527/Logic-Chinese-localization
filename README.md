##### *Q：* 我的版本太高或太低怎么办？
##### *A：* 如果游戏更新了但作者没有同步更新模组，可能是因为作者觉得不需要或是还没准备好新版本，若是游戏要求需要更高版本的模组可以试着调高mod.hjson里的minGameVersion至你游戏的版本。如果模组显示游戏版本过低可以试着先下最低版本的逻辑汉化补丁，然后调低mod.hjson里的minGameVersion至你的游戏版本。<br>
