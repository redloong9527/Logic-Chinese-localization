***Q：* 我的版本太高或太低怎么办？** <br>
***A：* 如果游戏更新了但作者没有同步更新模组，可能是因为作者觉得不需要更新或是还没准备好新版本，若是游戏要求需要更高版本的模组可以试着调高`mod.hjson`里的`minGameVersion`至你游戏的版本。如果模组显示游戏版本过低可以试着先下最低版本的逻辑汉化补丁，然后调低`mod.hjson`里的`minGameVersion`至你的游戏版本。** <br>
***Q：* 手机端如何查看中文词条？** <br>
***A：* 长按英文词条就可以了哦，就像原版那样** <br>
